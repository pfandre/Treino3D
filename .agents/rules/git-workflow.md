# Vercel Git Workflow

When working in this project, you must follow this deployment workflow:
- After making and verifying any code changes, you MUST automatically commit the changes.
- Use a descriptive commit message summarizing the changes.
- After committing, you MUST push the changes to the origin repository (`git push`).
- This is required because the repository is linked to Vercel, and pushing is the only way to trigger a live deployment.
